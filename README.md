Python Number Statistics

Description

Python Number Statistics is a beginner-friendly Python project that collects numbers entered by the user and calculates various statistics.

The program stops when the user enters 0.

Features

Calculates the total sum of entered numbers.
Counts how many numbers were entered.
Calculates the average.
Counts even and odd numbers.
Finds the maximum and minimum values.
Counts positive and negative numbers.
Handles cases where no numbers are entered.

Python

Variables
int() and str() conversions
input() and print()
if, elif, and else
while loops
Comparison operators
Arithmetic operators
Modulo operator (%)
Counters and accumulators
F-strings
How to Run

Download or clone this repository.
Open the project in PyCharm.
Run Number statistics.py.
Enter numbers when prompted.
Enter 0 to stop the program and display the statistics.
