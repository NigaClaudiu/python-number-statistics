Python Number Statistics
Description
Python Number Statistics is a beginner-friendly Python project that collects numbers entered by the user and calculates various statistics.

The program stops when the user enters 0.
Features
- Calculates the total sum of entered numbers.
- Counts how many numbers were entered.
- Calculates the average.
- Finds the maximum and minimum values.
- Counts positive and negative numbers.
- Counts even and odd numbers.
- Stores entered numbers in a list.
- Sorts numbers in ascending and descending order.
- Handles cases where no numbers are entered.
Python Concepts Practiced
- Variables and data types
- int() and input()
- if, elif and else
- while loops
- Lists and append()
- count and accumulators
- sum(), min() and max()
- sorted() and reverse=True
- Modulo operator (%)
- F-strings
- Basic input handling
How to Run
1. Download or clone this repository.
2. Open the project in PyCharm.
3. Run Number statistics.py.
4. Enter numbers when prompted.
5. Enter 0 to stop the program and display the statistics.
